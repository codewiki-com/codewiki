<Sheet title="资源与方法">
  <Row code="GET /orders/ord-42">读取资源表示且不改变资源状态；安全且幂等</Row>
  <Row code="HEAD /orders/ord-42">只读取响应元数据，不返回响应内容；安全且幂等</Row>
  <Row code="POST /orders">让集合处理一个表示；常用于创建成员，本身不保证幂等</Row>
  <Row code="PUT /orders/ord-42">在已知目标创建或替换表示；幂等</Row>
  <Row code="PATCH /orders/ord-42">按补丁媒体类型定义的规则执行部分修改；本身不保证幂等</Row>
  <Row code="DELETE /orders/ord-42">请求删除目标；预期效果是幂等的</Row>
  <Row code="OPTIONS /orders">查询目标支持的通信选项；安全且幂等</Row>
</Sheet>

<Sheet title="Node 客户端">
  <Row code="const response = await fetch('https://api.example.com/orders')">用 Node 24 的全局 `fetch` 发送 GET 请求</Row>
  <Row code="await fetch(url, { method: 'POST', headers: { 'content-type': 'application/json' }, body: JSON.stringify(order) })">发送 JSON，并明确指定请求媒体类型</Row>
  <Row code="response.ok">检查状态码是否在 200–299 范围内</Row>
  <Row code="response.headers.get('content-type')">以不区分大小写的方式读取响应头</Row>
  <Row code="const data = await response.json()">一次性消费响应内容并解析为 JSON</Row>
  <Row code="await fetch(url, { signal: AbortSignal.timeout(5000) })">五秒后中止请求</Row>
</Sheet>

<Sheet title="成功响应">
  <Row code="200 OK">返回成功的表示或操作结果</Row>
  <Row code="201 Created">说明请求已经创建资源</Row>
  <Row code="Location: /orders/ord-42">在 `201` 响应中标识新建资源</Row>
  <Row code="202 Accepted">说明处理已接受但尚未完成；还要定义客户端如何观察完成状态</Row>
  <Row code="204 No Content">说明操作成功且没有响应内容</Row>
</Sheet>

<Sheet title="客户端错误">
  <Row code="400 Bad Request">拒绝语法、消息构造或请求输入有误的请求</Row>
  <Row code="401 Unauthorized">拒绝缺少认证或凭据无效的请求，并返回质询</Row>
  <Row code="403 Forbidden">拒绝调用方无权执行但服务端已经理解的请求</Row>
  <Row code="404 Not Found">说明资源不存在，或隐藏调用方不应发现的资源</Row>
  <Row code="409 Conflict">说明请求与资源当前状态冲突</Row>
  <Row code="412 Precondition Failed">拒绝条件请求头求值为假的请求</Row>
  <Row code="422 Unprocessable Content">拒绝格式正确但指令无法处理的内容</Row>
</Sheet>

<Sheet title="服务端压力">
  <Row code="429 Too Many Requests">说明该客户端已超过速率限制</Row>
  <Row code="500 Internal Server Error">说明服务端发生意外故障，不暴露内部细节</Row>
  <Row code="502 Bad Gateway">说明网关收到无效的上游响应</Row>
  <Row code="503 Service Unavailable">说明服务因过载或维护而暂时不可用</Row>
  <Row code="504 Gateway Timeout">说明网关未能及时收到上游响应</Row>
  <Row code="Retry-After: 120">在 `429` 或 `503` 后要求客户端等待 120 秒</Row>
</Sheet>

<Sheet title="表示格式">
  <Row code="Content-Type: application/json">标明请求或响应内容的媒体类型</Row>
  <Row code="Accept: application/json">请求 JSON 响应表示</Row>
  <Row code="Content-Type: application/problem+json">标明 RFC 9457 问题详情文档</Row>
  <Row code="406 Not Acceptable">说明可用响应表示都不满足 `Accept`</Row>
  <Row code="415 Unsupported Media Type">拒绝格式或编码不受支持的请求内容</Row>
  <Row code="Content-Encoding: gzip">声明表示数据采用 gzip 内容编码</Row>
</Sheet>

<Sheet title="缓存">
  <Row code="Cache-Control: no-store">要求缓存不要存储此响应</Row>
  <Row code="Cache-Control: private, max-age=60">允许私有缓存在响应新鲜期间复用它</Row>
  <Row code="Cache-Control: public, max-age=300">在契约允许时，让共享缓存复用响应</Row>
  <Row code="ETag: &quot;order-7&quot;">为选定表示附加不透明验证器</Row>
  <Row code="If-None-Match: &quot;order-7&quot;">用实体标签重新验证缓存的表示</Row>
  <Row code="304 Not Modified">复用缓存的表示；该响应不携带消息内容</Row>
  <Row code="Vary: Accept-Encoding">为接受不同编码的请求保留独立缓存条目</Row>
</Sheet>

<Sheet title="并发与重试">
  <Row code="If-Match: &quot;order-7&quot;">仅在当前强实体标签匹配时执行修改</Row>
  <Row code="428 Precondition Required">要求客户端发送条件请求</Row>
  <Row code="idempotent: GET, HEAD, OPTIONS, PUT, DELETE">重复相同请求的预期效果与发送一次相同</Row>
  <Row code="not inherently idempotent: POST, PATCH">仅当应用契约提供安全去重语义时重试</Row>
  <Row code="Idempotency-Key: 7b1d7a90">同一逻辑操作的每次重试都复用应用定义的同一键和请求体</Row>
</Sheet>

<Sheet title="分页">
  <Row code="GET /orders?status=pending">用文档明确的查询参数过滤集合</Row>
  <Row code="GET /orders?limit=50">请求有界的页大小；服务端仍要强制执行上限</Row>
  <Row code="GET /orders?cursor=eyJpZCI6Im9yZC00MiJ9">用绑定到相同过滤条件与排序的不透明游标继续读取</Row>
  <Row code="ORDER BY created_at DESC, id DESC">用唯一决胜字段形成完整且确定的分页顺序</Row>
  <Row code="Link: &lt;/orders?cursor=next&gt;; rel=&quot;next&quot;">给出下一页目标，客户端无需自行构造</Row>
</Sheet>

<Sheet title="认证与 CORS">
  <Row code="Authorization: Bearer ACCESS_TOKEN">通过 TLS 向资源服务器发送 Bearer 访问令牌</Row>
  <Row code="WWW-Authenticate: Bearer realm=&quot;orders&quot;">质询缺少或使用无效 Bearer 凭据的请求</Row>
  <Row code="Origin: https://app.example.com">标明发起请求的浏览器源；它不能认证用户</Row>
  <Row code="Access-Control-Allow-Origin: https://app.example.com">允许该源的浏览器代码读取跨源响应</Row>
  <Row code="Access-Control-Allow-Methods: GET, POST">列出预检响应允许的方法</Row>
  <Row code="Access-Control-Allow-Headers: Authorization, Content-Type">列出预检允许的非简单请求头</Row>
  <Row code="Access-Control-Allow-Credentials: true">只与明确允许的源搭配，以准许浏览器携带凭据</Row>
</Sheet>

<Sheet title="契约演进">
  <Row code="GET /api/v1/orders">通过路径选择主版本 API 契约</Row>
  <Row code="Accept: application/vnd.example.orders.v2+json">通过内容协商选择版本化表示</Row>
  <Row code="Vary: Accept">防止缓存混用由 `Accept` 选择的不同表示</Row>
  <Row code="Deprecation: @1798761600">用 RFC 9651 日期标明弃用时刻，但不改变当前行为</Row>
  <Row code="Sunset: Thu, 01 Jul 2027 00:00:00 GMT">标明资源预计何时停止响应</Row>
</Sheet>
