<Sheet title="基础">
  <Row code="x: int = 5">类型注解是提示，不会在运行时自动检查</Row>
  <Row code="a, *rest = values">星号解包会收集剩余元素</Row>
  <Row code="value if ready else fallback">条件表达式会返回两个值中的一个</Row>
</Sheet>

<Sheet title="函数与作用域">
  <Row code="def collect(items=None):">用 `None` 避免可变默认参数</Row>
  <Row code="nonlocal count">重新绑定最近一层外部函数作用域中的名称</Row>
  <Row code="lambda x: x + offset">闭包从定义它的作用域读取自由变量</Row>
</Sheet>

<Sheet title="迭代与异步">
  <Row code="enumerate(items, start=1)">为每个元素配上从一开始的序号</Row>
  <Row code="zip(xs, ys, strict=True)">输入长度不一致时立即报错</Row>
  <Row code="async with TaskGroup() as group:">让相关任务共享一个结构化生命周期</Row>
</Sheet>
