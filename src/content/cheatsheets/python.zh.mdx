<Sheet title="绑定与分支">
  <Row code="name = value">绑定或重新绑定名称，不复制对象</Row>
  <Row code="first, *middle, last = values">解包时把中间元素收集到新列表</Row>
  <Row code="result = value if condition else fallback">只求值并返回选中的分支</Row>
  <Row code="if (match := pattern.search(text)):">只求值一次，同时保留匹配对象</Row>
  <Row code="match command:">从上到下用各个 `case` 匹配一次求值的对象</Row>
  <Row code="case {'action': action, **rest}:">捕获一个映射值和其余未匹配的键值</Row>
</Sheet>

<Sheet title="集合">
  <Row code="items[start:stop:step]">选取序列切片，不修改原序列</Row>
  <Row code="[project(item) for item in items if keep(item)]">筛选并转换为新列表</Row>
  <Row code="{key(item): value(item) for item in items}">用生成的键值对构造字典</Row>
  <Row code="unique = set(items)">对可哈希值去重，不保留输入顺序</Row>
  <Row code="mapping.get(key, fallback)">只在键不存在时返回后备值</Row>
  <Row code="sorted(items, key=key_fn, reverse=True)">按派生键排序并返回新列表</Row>
</Sheet>

<Sheet title="函数与作用域">
  <Row code="def fetch(url, /, timeout=5, *, retries=2):">把 `url` 限定为仅限位置参数，把 `retries` 限定为仅限关键字参数</Row>
  <Row code="def collect(*items, **options):">收集额外的位置参数和关键字参数</Row>
  <Row code="result = function(*args, **kwargs)">把可迭代对象和映射解包为调用参数</Row>
  <Row code="nonlocal count">重新绑定最近一层外部函数中的绑定</Row>
  <Row code="@functools.wraps(function)">复制被包装函数的元数据，并公开其引用</Row>
  <Row code="@functools.cache">按可哈希参数缓存调用结果，不限制缓存大小</Row>
</Sheet>

<Sheet title="对象与抽象基类">
  <Row code="from abc import ABC, abstractmethod">导入定义抽象基类所需的辅助对象</Row>
  <Row code="class Service(ABC):">声明由 `ABCMeta` 管理的类</Row>
  <Row code="@abstractmethod">要求具体子类覆盖所标记的方法</Row>
  <Row code="super().__init__()">调用方法解析顺序中的下一个初始化方法</Row>
  <Row code="@dataclass(slots=True, frozen=True)">生成使用槽且禁止字段赋值的数据类</Row>
  <Row code="items: list[str] = field(default_factory=list)">为每个数据类实例创建新列表</Row>
</Sheet>

<Sheet title="迭代与惰性管道">
  <Row code="enumerate(items, start=1)">为每个元素配上从一开始的计数</Row>
  <Row code="zip(left, right, strict=True)">可迭代对象长度不同时抛出 `ValueError`</Row>
  <Row code="(project(item) for item in items)">创建惰性的生成器表达式</Row>
  <Row code="yield from source">委托迭代和生成器协议操作</Row>
  <Row code="itertools.islice(source, start, stop)">惰性选取迭代器切片</Row>
  <Row code="itertools.chain.from_iterable(groups)">惰性展开一层可迭代对象</Row>
</Sheet>

<Sheet title="错误与清理">
  <Row code="raise ValueError(message)">明确拒绝无效值</Row>
  <Row code="raise DomainError(message) from error">把原始失败保留为直接原因</Row>
  <Row code="except (ValueError, TypeError) as error:">只捕获列出的异常类型</Row>
  <Row code="with open(path, encoding='utf-8') as stream:">退出代码块时关闭文本流</Row>
  <Row code="with contextlib.suppress(FileNotFoundError):">只忽略代码块中指定的异常</Row>
  <Row code="with contextlib.ExitStack() as stack:">按相反顺序释放数量动态变化的资源</Row>
</Sheet>

<Sheet title="异步与并发">
  <Row code="asyncio.run(main())">运行一个顶层协程并关闭其事件循环</Row>
  <Row code="result = await coroutine()">挂起当前任务，直到可等待对象完成</Row>
  <Row code="async with asyncio.TaskGroup() as group:">退出作用域前等待所有子任务</Row>
  <Row code="task = group.create_task(work())">启动一个由任务组管理的协程</Row>
  <Row code="async with asyncio.timeout(5):">把代码块内的等待限制为五秒</Row>
  <Row code="result = await asyncio.to_thread(blocking_call)">把阻塞式 I/O 移出事件循环线程</Row>
</Sheet>

<Sheet title="路径与进程">
  <Row code="path = Path('data/config.toml')">构造路径，不访问文件系统</Row>
  <Row code="text = path.read_text(encoding='utf-8')">读取并解码文本文件，然后将其关闭</Row>
  <Row code="path.write_text(text, encoding='utf-8')">覆盖并编码文本文件，然后将其关闭</Row>
  <Row code="path.mkdir(parents=True, exist_ok=True)">幂等地创建缺失的父目录</Row>
  <Row code="result = subprocess.run(args, check=True, text=True, capture_output=True)">捕获文本输出，并在退出状态非零时抛出异常</Row>
  <Row code="with tempfile.TemporaryDirectory() as directory:">退出代码块时删除临时目录</Row>
</Sheet>

</Sheet>
