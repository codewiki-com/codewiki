<Sheet title="Goroutine 与通道">
  <Row code="go process(job)">并发启动调用，不等待其结果</Row>
  <Row code="jobs := make(chan Job, 8)">创建最多缓冲八个值的通道</Row>
  <Row code="jobs <- job">发送值；没有接收者或缓冲空间时阻塞</Row>
  <Row code="job, ok := <-jobs">接收值，并检测已关闭通道是否排空</Row>
  <Row code="close(jobs)">发出不再发送值的信号；由发送方关闭</Row>
  <Row code="select { case result := <-done: use(result); case <-ctx.Done(): return ctx.Err() }">等待结果或取消信号</Row>
</Sheet>
