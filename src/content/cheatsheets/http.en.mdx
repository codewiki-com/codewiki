<Sheet title="Resources and methods">
  <Row code="GET /orders/ord-42">retrieve a representation without changing resource state; safe and idempotent</Row>
  <Row code="HEAD /orders/ord-42">retrieve response metadata without response content; safe and idempotent</Row>
  <Row code="POST /orders">ask a collection to process a representation; commonly creates a member and is not inherently idempotent</Row>
  <Row code="PUT /orders/ord-42">create or replace the representation at a known target; idempotent</Row>
  <Row code="PATCH /orders/ord-42">apply a partial modification defined by the patch media type; not inherently idempotent</Row>
  <Row code="DELETE /orders/ord-42">request removal of the target; the intended effect is idempotent</Row>
  <Row code="OPTIONS /orders">request communication options for the target; safe and idempotent</Row>
</Sheet>

<Sheet title="Node client">
  <Row code="const response = await fetch('https://api.example.com/orders')">send a GET request with the Node 24 global `fetch`</Row>
  <Row code="await fetch(url, { method: 'POST', headers: { 'content-type': 'application/json' }, body: JSON.stringify(order) })">send JSON with an explicit request media type</Row>
  <Row code="response.ok">test whether the status is in the 200–299 range</Row>
  <Row code="response.headers.get('content-type')">read a response header case-insensitively</Row>
  <Row code="const data = await response.json()">consume the response content once and parse it as JSON</Row>
  <Row code="await fetch(url, { signal: AbortSignal.timeout(5000) })">abort the request after five seconds</Row>
</Sheet>

<Sheet title="Success responses">
  <Row code="200 OK">return a successful representation or operation result</Row>
  <Row code="201 Created">report that the request created a resource</Row>
  <Row code="Location: /orders/ord-42">identify the created resource in a `201` response</Row>
  <Row code="202 Accepted">report accepted but unfinished processing; define how clients observe completion</Row>
  <Row code="204 No Content">report success with no response content</Row>
</Sheet>

<Sheet title="Client failures">
  <Row code="400 Bad Request">reject malformed syntax, framing, or request input</Row>
  <Row code="401 Unauthorized">reject missing or invalid authentication and send a challenge</Row>
  <Row code="403 Forbidden">refuse an understood request that the caller is not allowed to perform</Row>
  <Row code="404 Not Found">report an absent resource, or conceal one the caller must not discover</Row>
  <Row code="409 Conflict">report a conflict with the resource's current state</Row>
  <Row code="412 Precondition Failed">reject a request whose conditional header evaluated false</Row>
  <Row code="422 Unprocessable Content">reject well-formed content whose instructions cannot be processed</Row>
</Sheet>

<Sheet title="Server pressure">
  <Row code="429 Too Many Requests">report that this client exceeded a rate limit</Row>
  <Row code="500 Internal Server Error">report an unexpected server failure without exposing internals</Row>
  <Row code="502 Bad Gateway">report that a gateway received an invalid upstream response</Row>
  <Row code="503 Service Unavailable">report temporary overload or maintenance</Row>
  <Row code="504 Gateway Timeout">report that a gateway did not receive an upstream response in time</Row>
  <Row code="Retry-After: 120">tell the client to wait 120 seconds after `429` or `503`</Row>
</Sheet>

<Sheet title="Representations">
  <Row code="Content-Type: application/json">identify the media type of request or response content</Row>
  <Row code="Accept: application/json">request a JSON response representation</Row>
  <Row code="Content-Type: application/problem+json">identify an RFC 9457 problem-details document</Row>
  <Row code="406 Not Acceptable">report that no available response representation meets `Accept`</Row>
  <Row code="415 Unsupported Media Type">reject request content in an unsupported format or encoding</Row>
  <Row code="Content-Encoding: gzip">declare that the representation data uses gzip content coding</Row>
</Sheet>

<Sheet title="Caching">
  <Row code="Cache-Control: no-store">tell caches not to store this response</Row>
  <Row code="Cache-Control: private, max-age=60">allow a private cache to reuse the response while it is fresh</Row>
  <Row code="Cache-Control: public, max-age=300">allow shared caches to reuse the response when the contract permits it</Row>
  <Row code="ETag: &quot;order-7&quot;">attach an opaque validator to the selected representation</Row>
  <Row code="If-None-Match: &quot;order-7&quot;">revalidate a cached representation with its entity tag</Row>
  <Row code="304 Not Modified">reuse the cached representation; the response carries no message content</Row>
  <Row code="Vary: Accept-Encoding">keep separate cache entries for requests with different accepted encodings</Row>
</Sheet>

<Sheet title="Concurrency and retries">
  <Row code="If-Match: &quot;order-7&quot;">apply a mutation only while the current strong entity tag matches</Row>
  <Row code="428 Precondition Required">require the client to make the request conditional</Row>
  <Row code="idempotent: GET, HEAD, OPTIONS, PUT, DELETE">repeating an identical request has the same intended effect as one request</Row>
  <Row code="not inherently idempotent: POST, PATCH">retry only when the application contract supplies safe deduplication semantics</Row>
  <Row code="Idempotency-Key: 7b1d7a90">reuse one application-defined key and payload for every retry of the same logical operation</Row>
</Sheet>

<Sheet title="Pagination">
  <Row code="GET /orders?status=pending">filter a collection with a documented query parameter</Row>
  <Row code="GET /orders?limit=50">request a bounded page size; the server still enforces a maximum</Row>
  <Row code="GET /orders?cursor=eyJpZCI6Im9yZC00MiJ9">continue from an opaque cursor bound to the same filters and ordering</Row>
  <Row code="ORDER BY created_at DESC, id DESC">use a unique tie-breaker to make the page order total and deterministic</Row>
  <Row code="Link: &lt;/orders?cursor=next&gt;; rel=&quot;next&quot;">advertise the next page target without asking the client to construct it</Row>
</Sheet>

<Sheet title="Auth and CORS">
  <Row code="Authorization: Bearer ACCESS_TOKEN">send a bearer access token over TLS to the resource server</Row>
  <Row code="WWW-Authenticate: Bearer realm=&quot;orders&quot;">challenge a request with missing or invalid bearer credentials</Row>
  <Row code="Origin: https://app.example.com">identify the initiating browser origin; this is not user authentication</Row>
  <Row code="Access-Control-Allow-Origin: https://app.example.com">allow that origin to expose the cross-origin response to browser code</Row>
  <Row code="Access-Control-Allow-Methods: GET, POST">list methods allowed by the preflight response</Row>
  <Row code="Access-Control-Allow-Headers: Authorization, Content-Type">list non-safelisted request headers allowed by preflight</Row>
  <Row code="Access-Control-Allow-Credentials: true">permit credentialed browser requests only with an explicit allowed origin</Row>
</Sheet>

<Sheet title="Evolution">
  <Row code="GET /api/v1/orders">select a major API contract in the path</Row>
  <Row code="Accept: application/vnd.example.orders.v2+json">select a versioned representation through content negotiation</Row>
  <Row code="Vary: Accept">prevent a cache from mixing representations selected by `Accept`</Row>
  <Row code="Deprecation: @1798761600">signal a deprecation instant as an RFC 9651 date without changing current behavior</Row>
  <Row code="Sunset: Thu, 01 Jul 2027 00:00:00 GMT">signal when the resource is expected to become unresponsive</Row>
</Sheet>
