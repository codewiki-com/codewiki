<Sheet title="绑定与控制流">
  <Row code="let value = source;">绑定不可变局部变量；需要改变类型时，用新的`let`遮蔽它</Row>
  <Row code="let mut count = 0;">允许重新赋值和原地修改</Row>
  <Row code="const LIMIT: usize = 100;">声明带类型的编译期常量</Row>
  <Row code="let Some(id) = maybe_id else { return; };">匹配到`Some`时取出值，否则退出当前控制流</Row>
  <Row code="match result { Ok(value) =&gt; value, Err(error) =&gt; return Err(error) }">穷尽处理所有变体，并原样返回错误</Row>
  <Row code="while let Some(item) = stack.pop() { consume(item); }">持续取值，直到模式不再匹配</Row>
</Sheet>

<Sheet title="所有权与借用">
  <Row code="inspect(&amp;value);">借出共享访问权，不转移所有权</Row>
  <Row code="update(&amp;mut value);">借出独占可变访问权，直到该借用最后一次使用</Row>
  <Row code="let moved = value;">转移所有权；除非类型实现`Copy`，否则原绑定失效</Row>
  <Row code="let copied = number;">复制实现`Copy`的值，使两个绑定都可继续使用</Row>
  <Row code="let cloned = value.clone();">通过`Clone`显式创建副本</Row>
  <Row code="let old = std::mem::take(&amp;mut value);">用`Default::default()`替换原值，并取得旧值的所有权</Row>
  <Row code="drop(guard);">在作用域结束前释放拥有的资源</Row>
</Sheet>

<Sheet title="字符串与集合">
  <Row code="fn normalize(text: &amp;str) -&gt; String { text.trim().to_owned() }">借用UTF-8输入，返回拥有所有权的文本</Row>
  <Row code="text.chars()">迭代Unicode标量值，而不是字素簇</Row>
  <Row code="text.as_bytes()">不分配内存，直接借用底层UTF-8字节</Row>
  <Row code="String::from_utf8(bytes)?">校验UTF-8，并复用拥有所有权的字节缓冲区</Row>
  <Row code="Vec::with_capacity(count)">已知预计元素数量时预留空间</Row>
  <Row code="counts.entry(key).or_insert(0)">为缺失的映射项插入默认值，并取得可变借用</Row>
  <Row code="queue.pop_front()">以`Option`返回并移除`VecDeque`中最早的元素</Row>
</Sheet>

<Sheet title="迭代器与闭包">
  <Row code="items.iter()">生成共享引用，并保留集合所有权</Row>
  <Row code="items.iter_mut()">生成独占引用，用于原地修改</Row>
  <Row code="items.into_iter()">消耗集合，并生成拥有所有权的元素</Row>
  <Row code="iter.filter_map(parse).collect::&lt;Vec&lt;_&gt;&gt;()">丢弃`None`，收集成功转换的值</Row>
  <Row code="iter.collect::&lt;Result&lt;Vec&lt;_&gt;, _&gt;&gt;()?">收集成功值，遇到第一个错误时停止</Row>
  <Row code="move |item| process(item, &amp;config)">按值捕获`config`，让闭包可以活得比当前作用域更久</Row>
  <Row code="F: FnMut(&amp;Item) -&gt; bool">接受可重复调用且能修改捕获状态的谓词</Row>
</Sheet>

<Sheet title="trait与类型">
  <Row code="#[derive(Debug, Clone, PartialEq)] struct Point(i32, i32);">为数据类型生成标准trait实现</Row>
  <Row code="struct UserId(u64);">使用newtype模式为基本类型赋予独立的领域类型</Row>
  <Row code="enum State&lt;T&gt; { Ready(T), Closed }">用可携带数据的变体描述封闭状态集合</Row>
  <Row code="fn show&lt;T: Display&gt;(value: &amp;T) { println!(&quot;{value}&quot;); }">用泛型trait约束要求一种能力</Row>
  <Row code="trait Source { type Item; fn next(&amp;mut self) -&gt; Option&lt;Self::Item&gt;; }">让每个实现选择一种关联项类型</Row>
  <Row code="Box&lt;dyn Draw + Send&gt;">拥有可跨线程传递、隐藏具体类型的实现者</Row>
  <Row code="&lt;User as Display&gt;::fmt(&amp;user, formatter)">用完全限定语法明确选择trait实现</Row>
</Sheet>

<Sheet title="Option与Result">
  <Row code="type LoadResult&lt;T&gt; = Result&lt;T, LoadError&gt;;">为可复用的结果类型命名，同时保留明确的错误类型</Row>
  <Row code="let value = operation()?;">成功时取值，失败时立即返回转换后的残差</Row>
  <Row code="option.ok_or_else(|| Error::Missing(key))?">把缺失值转换为按需构造的错误</Row>
  <Row code="option.and_then(parse)">串联另一个返回`Option`的函数</Row>
  <Row code="result.map(transform)">只转换成功值</Row>
  <Row code="result.map_err(Error::from)">只转换错误值</Row>
  <Row code="matches!(status, Status::Ready(_))">测试模式是否匹配，并返回布尔值</Row>
</Sheet>

<Sheet title="anyhow与thiserror">
  <Row code="type AppResult&lt;T&gt; = anyhow::Result&lt;T&gt;;">在应用边界擦除具体错误类型</Row>
  <Row code="read(path).with_context(|| format!(&quot;reading {path}&quot;))?">导入`anyhow::Context`后，仅在失败时添加上下文</Row>
  <Row code="anyhow::bail!(&quot;invalid port: {port}&quot;);">立即返回临时构造的应用错误</Row>
  <Row code="anyhow::ensure!(port &gt; 0, &quot;port must be positive&quot;);">条件不成立时返回应用错误</Row>
  <Row code="#[derive(Debug, thiserror::Error)] enum LoadError { #[error(&quot;missing config&quot;)] Missing }">定义可供调用方匹配的具体错误类型</Row>
  <Row code="#[error(&quot;cannot read {path}: {source}&quot;)] Read { path: PathBuf, #[source] source: std::io::Error }">格式化变体，同时保留底层错误源</Row>
  <Row code="Io(#[from] std::io::Error)">为变体生成`From`转换和错误源报告</Row>
</Sheet>

<Sheet title="线程与共享状态">
  <Row code="let handle = std::thread::spawn(move || work(data));">把任务数据的所有权移入新的操作系统线程</Row>
  <Row code="let result = handle.join().expect(&quot;worker panicked&quot;);">等待线程结束，并明确暴露panic</Row>
  <Row code="let shared = Arc::new(Mutex::new(value));">组合共享所有权与同步可变性</Row>
  <Row code="let mut guard = shared.lock().unwrap();">取得可变访问权；需要恢复时应处理锁中毒</Row>
  <Row code="let read_guard = lock.read().unwrap();">通过`RwLock`守卫允许多个读取者并发访问</Row>
  <Row code="let (sender, receiver) = std::sync::mpsc::sync_channel(capacity);">创建有界通道，缓冲区满时施加背压</Row>
  <Row code="sender.send(value)?;">把值转移给接收端；连接断开时返回错误</Row>
</Sheet>

<Sheet title="异步与Tokio">
  <Row code="async fn fetch() -&gt; Result&lt;Data, Error&gt; { request().await }">返回future，其函数体在被轮询时才运行</Row>
  <Row code="let value = future.await?;">暂停到操作完成，并传播失败</Row>
  <Row code="let handle = tokio::spawn(async move { work(data).await });">在运行时中生成拥有数据的`Send + 'static`任务</Row>
  <Row code="let (left, right) = tokio::try_join!(load_a(), load_b())?;">并发推进可失败的future，遇到错误时停止</Row>
  <Row code="tokio::select! { value = task =&gt; value, }">竞速已启用的分支；未胜出的future必须可安全取消</Row>
  <Row code="let value = tokio::time::timeout(duration, operation()).await??;">限制等待时间，并传播超时错误和操作错误</Row>
  <Row code="tokio::task::spawn_blocking(|| blocking_work()).await?;">把阻塞工作移出异步工作线程</Row>
</Sheet>

  <Row code="cargo test --workspace">运行工作区内所有package的测试</Row>
  <Row code="cargo clippy --all-targets --all-features -- -D warnings">检查所有target，并把任何警告视为失败</Row>

<Sheet title="unsafe与FFI">

  <Row code="unsafe extern &quot;C&quot; { fn strlen(s: *const c_char) -&gt; usize; }">声明Rust无法验证调用契约的外部函数</Row>
