### Findings

#### Critical

#### Important

1. **Task 17 is not on this branch.** `package.json:10-24` has neither `content:write` nor `content:check`, and `scripts/content/write.sh`, `scripts/content/lib/write-brief.ts`, and all five requested `prompts/write-*.md` files are absent. The Task 17 commit exists on `p2-t17-content-runner` (`db0637c`) but is not an ancestor of `p2-learning-layer`. Failure scenario: the required dry run exits 254 before validating an input, and none of the requested journal, explicit-path commit, or interrupt-safety properties are available to review or use. Smallest fix: integrate the Task 17 commit into this branch, resolve it against the P2b schemas/scripts, then run its unit tests, content validation, and all five no-side-effect dry runs.

2. **Every Try-to-break link loses its challenged code, and Chinese links cross to the English route.** `src/components/TryToBreak.astro:18-23` compresses a bare source string, emits an empty `lang`, and hard-codes `/playground/`; `src/islands/Playground.tsx:96-110` accepts that legacy bare-source form only when `lang` normalizes successfully. Verified in Chromium from `/python/closures/`: clicking the nudge opened the Python starter `print(1 + 1)`, not the challenged closure example. On `/zh/`, the same link also opens English UI. `tests/e2e/topic.spec.ts:283-302` only decompresses the href and never follows it, so the gate misses the failure. Smallest fix: propagate the runnable fence language into `TryToBreak`, use `encodeState({ lang, code })`, localize the playground path, and make the e2e test navigate and assert the editor contents on both locales.

3. **A bilingual count mismatch can silently pair the wrong translation.** `src/markdown/rehype-block-ids.ts:80-92` numbers blocks under localized heading slugs, while `src/islands/Bilingual.tsx:107-121` aliases headings by array index and `src/islands/Bilingual.tsx:235-265` pairs the resulting ordinal IDs. If one locale omits a heading, every later section can be aliased to the preceding section; if it omits a paragraph, later paragraphs in that section shift and are displayed beside the wrong source paragraph. The `data-bilingual-missing` count only catches an unmatched tail and does not prevent the false pairs. Smallest fix: add the specified build-time structural alignment check and disable `aligned` on mismatch; defensively compare heading counts and per-section block-kind sequences at runtime and leave a mismatched section monolingual.

4. **Callouts are cloned wholesale, so their box and any nested code are duplicated.** `src/markdown/rehype-block-ids.ts:89-92` treats a callout as an opaque block and stops walking its children; `src/lib/bilingual.ts:23-32` excludes only a top-level codebox; `src/islands/Bilingual.tsx:244-262` then clones the callout's full `outerHTML`. This violates the specified single-box callout treatment, and a callout containing a codebox produces a second code block and a dead cloned Run control. Smallest fix: keep one structural callout and merge only its translated text children, explicitly stripping/skipping nested codeboxes, diagrams, and generated action chrome.

5. **`zh-en` does not reverse headings, TOC labels, or vocabulary.** Body blocks honor `sourceFirst` in `src/islands/Bilingual.tsx:241-262`, but `addHeadingSubtitles` always appends the alternate label (`src/islands/Bilingual.tsx:173-184`), the TOC always appends it (`src/islands/Toc.tsx:90-104`), and vocabulary always appends English before Chinese (`src/islands/Bilingual.tsx:201-218`). Failure scenario: on an English page in `zh-en` mode the Chinese paragraph is first, but the heading and TOC remain English-first, so the requested reading order is internally inconsistent. Smallest fix: pass the selected mode into all three renderers and prepend/append each language according to that mode; add assertions for headings, TOC, and vocabulary, not only body blocks.

6. **Shared URL decoding has no payload bound.** `src/lib/lz.ts:19-36` fully decompresses and accepts arbitrary-length `code` and `tests`. A verified 5,000,000-character repeated source compresses to a 5,745-character query value and is accepted as a 5 MB editor value. A crafted link can therefore allocate a very large string and stall editor mounting despite looking like a modest URL. Smallest fix: define URL-state limits, reject over-limit encoded input early, reject decoded `code`/`tests` before storing or mounting them, and test a high-compression-ratio payload as well as corrupt input.

7. **The SQL seed capability cannot be supplied by any example or code fence.** `src/lib/runners/protocol.ts:18-26` and `src/lib/runners/sql.ts:165-180` support `RunRequest.seed`, but the fence parser has no seed field (`src/markdown/shiki-meta.ts:10-33`), the examples endpoint omits it (`src/pages/api/examples.json.ts:32-42`), and the playground run request passes only `id`, `lang`, and `code` (`src/islands/Playground.tsx:339-344`). Failure scenario: a documented SQL example such as `SELECT * FROM users` cannot create its per-example fixture table and fails with `no such table`. Smallest fix: define and parse seed metadata, carry it through the rendered codebox/examples JSON and example state, and pass it to `run`; add an e2e example whose query depends on seeded rows.

#### Minor

1. **The localization regression gate omits both new P2b page types.** `tests/e2e/localization.spec.ts:50-62` does not include `/zh/playground/` or `/zh/ai/prompt-builder/`. Manual checks with JavaScript enabled and disabled found no current English UI leakage (the playground's visible `Python` label is a language name), but a future untranslated control on either page would not fail CI. Smallest fix: add both routes to `PAGES` and retain the existing technical-name allowlist.

2. **Two task-era comments are stale merge seams.** `scripts/check-dist-links.mjs:23-24` says Task 13 will remove the exception even though `KNOWN_LATER` is already empty, and `src/data/site.ts:23-26` leaves an orphan `// Task 14` after the now-enabled rules flag. Failure scenario: maintainers infer unfinished flag/link work where none remains. Smallest fix: delete or rewrite the two comments to describe current behavior.
