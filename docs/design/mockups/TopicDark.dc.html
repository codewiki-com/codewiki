What a closure is

A free variable is a name a function uses but does not define. When the inner function outlives the outer one, Python has to keep those variables alive somewhere. That bundle of function plus captured variables is the closure.

自由变量指的是函数用到，但没有在函数内部定义的名字。当内层函数比外层函数活得更久时，Python 必须把这些变量保存在某处。这个“函数 + 被捕获变量”的组合就是闭包。

make_counter.py
Copy Run
def make_counter(): count = 0 def step(): nonlocal count # write to the captured variable count += 1 return count return step tick = make_counter() print(tick(), tick(), tick()) print(tick.__closure__[0].cell_contents) # peek inside
stdout 1 2 3 3

Late binding: the trap

Python looks a captured variable up when the inner function runs, not when it is defined. Build several closures in a loop and they all share the same loop variable.

Python 在内层函数运行时才去查找被捕获的变量，而不是在定义时。在循环里创建多个闭包，它们共享同一个循环变量。

predictWhat does this print? 1 of 2 · adds to flashcards
fns = [lambda: i for i in range(3)] print([f() for f in fns])
[0, 1, 2]your guess
[2, 2, 2]correct
NameError: name 'i' is not defined

All three lambdas capture the same i. By the time any of them runs, the loop has finished and i is 2. Pin the value with lambda i=i: i.

PITFALL

Assigning to a captured name without nonlocal silently creates a new local variable, so count += 1 fails with UnboundLocalError. Mutating a captured list or dict needs no keyword at all.
