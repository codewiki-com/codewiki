Basics

x: int = 5annotation is a hint, not a check
a, *rest = seqstar-unpacking
if 0 < x < 10:chained comparison
x if cond else yconditional expression
match cmd: case ["go", d]:structural pattern matching
x := f()assignment expression (walrus)

Strings

f"{x!r:>8}"repr, right-aligned width 8
f"{n:,.2f}"thousands + 2 decimals
f"{x=}"prints x=5 for debugging
", ".join(parts)join beats += in loops
s.removeprefix("v")3.9+, no regex needed
t"..."template strings, 3.14

Collections

d.get(k, default)no KeyError
d.setdefault(k, [])insert-if-missing, returns value
a | bdict merge (3.9+), right wins
Counter(words).most_common(3)top three
defaultdict(list)grouping without checks
frozenset(s)hashable set

Comprehensions & iteration

[f(x) for x in xs if p(x)]filter then map
{k: v for k, v in pairs}dict comprehension
(x for x in xs)lazy generator
for i, x in enumerate(xs, 1):index from 1
for a, b in zip(xs, ys, strict=True):fail on length mismatch
any(p(x) for x in xs)short-circuits

Functions

def f(a, /, b, *, c):positional-only · keyword-only
def f(x, items=None):never a mutable default
*args, **kwargscollect extras
nonlocal countrebind in the enclosing scope
@functools.cachememoise pure functions
@functools.wraps(fn)keep name and docstring in decorators

Classes

@dataclass(slots=True, frozen=True)immutable value object
field(default_factory=list)per-instance mutable default
@propertycomputed attribute
def __repr__(self):unambiguous, for developers
class P(Protocol):structural typing
super().__init__()cooperative init

Errors

except ValueError as e:catch the narrowest type
raise NewError(...) from ekeep the cause chain
try / else / finallyelse runs only without exception
except* TimeoutError:exception groups, 3.11+
e.add_note("while ...")context for the traceback
contextlib.suppress(FileNotFoundError)ignore on purpose, visibly

Files & paths

Path("a") / "b.txt"join with /
p.read_text(encoding="utf-8")always name the encoding
with open(p) as f:closes on exit
p.glob("**/*.py")recursive match
p.parent.mkdir(parents=True, exist_ok=True)ensure directory
json.dumps(obj, indent=2, ensure_ascii=False)readable JSON, real 中文
