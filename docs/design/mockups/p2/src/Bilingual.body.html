whatA closure is a function that keeps access to bindings from an enclosing function after that function returns.闭包会在外层函数返回后，继续访问定义它时所在外层函数中的绑定。

What a closure is

闭包是什么
closure闭包free variable自由变量enclosing scope外层作用域binding绑定

A closure is a function paired with access to bindings from the lexical environment where the function was defined. In Python, the function is usually an inner function returned by an outer function. The outer call can finish, but any bindings needed by the inner function remain available.

闭包是一个函数，加上它对定义处词法环境中绑定的访问权。在 Python 里，这个函数通常是外层函数返回的内层函数。外层调用可以结束，但内层函数需要的绑定会继续存在。

A name used inside a function but bound outside it is a free variable. The function scope that supplies that binding is its enclosing scope. Together, the function's code and those retained bindings form the closure.

在函数内部使用、却在函数外部绑定的名字叫自由变量。提供这个绑定的函数作用域叫它的外层作用域。函数的代码加上这些被保留的绑定，合起来就是闭包。

make_counter.py
CopyResetRun
def make_counter(): count = 0 def tick(): nonlocal count count += 1 return count return tick tick = make_counter() print(tick(), tick(), tick())
$ python make_counter.py1 2 3

The counter keeps working after make_counter has returned because count lives in a cell that both functions share, not in the outer call's frame.

在 make_counter 返回之后计数器仍然能工作，因为 count 存在两个函数共享的 cell 里，而不是外层调用的栈帧里。

pitfall · 陷阱Forgetting nonlocal makes count += 1 create a new local name, and the read before the write raises UnboundLocalError.忘写 nonlocal 时，count += 1 会创建一个新的局部名字，写之前的那次读取会抛出 UnboundLocalError。
