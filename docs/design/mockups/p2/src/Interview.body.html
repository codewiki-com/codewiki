03What does a closure capture, and what goes wrong in a loop?mid · commonhide ▴

A closure keeps a reference to the binding, not a copy of the value. The inner function looks the name up in a cell when it runs, so it sees whatever the enclosing scope holds at call time.

In a loop that creates several closures over the loop variable, all of them share one cell, and the loop has finished by the time they run, so each returns the last value. The fix is to bind the current value at creation time, either with a default argument or by calling a factory function.

fns = [lambda i=i: i for i in range(3)] # default binds i now [f() for f in fns] # [0, 1, 2]

If they push further: mention nonlocal for rebinding, and that __closure__ exposes the cells.
