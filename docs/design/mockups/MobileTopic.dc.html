What a closure is

A free variable is a name a function uses but does not define. When the inner function outlives the outer one, Python has to keep those variables alive somewhere. That bundle is the closure.

自由变量指的是函数用到，但没有在函数内部定义的名字。当内层函数比外层函数活得更久时，Python 必须把这些变量保存在某处。这个组合就是闭包。

make_counter.py Run
def make_counter(): count = 0 def step(): nonlocal count count += 1 return count return step tick = make_counter() print(tick(), tick(), tick())
stdout 1 2 3

Late binding: the trap

Python looks a captured variable up when the inner function runs, not when it is defined.

Python 在内层函数运行时才去查找被捕获的变量，而不是在定义时。

fns = [lambda: i for i in range(3)] print([f() for f in fns])
