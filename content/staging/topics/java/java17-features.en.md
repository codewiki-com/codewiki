Java 17 is the second Long-Term Support (LTS) version after Java 11, officially released in September 2021. It consolidates numerous important features introduced from Java 12 to Java 17, making it an ideal target version for enterprise application upgrades. We analyze in depth the five most important language features in Java 17: Sealed Classes, Pattern Matching for instanceof, Records, Text Blocks, and Switch Expressions.

## Concept Explanation

### Java Version Evolution and LTS Strategy

Since Java 9, Oracle adopted a rapid release cadence of a new version every six months, with an LTS version released every three years. LTS versions receive at least eight years of support, making them the preferred choice for enterprise production environments.

| LTS Version | Release Date | Key Features |
|-------------|--------------|--------------|
| Java 8  | March 2014 | Lambda, Stream API, Optional |
| Java 11 | September 2018 | var, HTTP Client, Mature Modules |
| Java 17 | September 2021 | Sealed Classes, Records, Pattern Matching |
| Java 21 | September 2023 | Virtual Threads, Record Patterns |

### Why Choose Java 17

Java 17 as an LTS version offers the following advantages:

1. **Long-term Support**: Receives long-term maintenance from Oracle and major JDK vendors
2. **Mature Features**: Consolidates stable features officially released after multiple preview versions
3. **Performance Improvements**: Contains numerous JVM performance optimizations and garbage collector improvements
4. **Ecosystem Compatibility**: Required by mainstream frameworks like Spring Boot 3.x, Jakarta EE 10
5. **Security Enhancements**: Removed unsafe APIs, enhanced security default configurations

### Java 17 Core New Features Overview

The five core language features introduced in Java 17 work together to drive Java toward a more modern, safer, and more concise direction:

- **Sealed Classes**: Restrict class inheritance hierarchy, enhance type safety
- **Pattern Matching for instanceof**: Simplify type checking and casting
- **Records**: Concise immutable data class definitions
- **Text Blocks**: Elegant representation of multi-line strings
- **Switch Expressions**: Enhanced switch statement supporting expression form

## Core Principles

### Sealed Classes Design Principles

Sealed classes control inheritance hierarchy through `sealed`, `permits`, `non-sealed`, and `final` keywords.

**Class Hierarchy Constraint Mechanism**:

```
sealed interface Shape
    ├── Circle (final)        → Cannot be inherited
    ├── Rectangle (final)     → Cannot be inherited
    └── Polygon (non-sealed)  → Open for inheritance
            └── Triangle
            └── Pentagon
            └── ... any subclass
```

**Compiler Exhaustiveness Check**: When sealed classes are used in switch expressions, the compiler can verify whether all possible subtypes are covered, without needing a default branch.

### Pattern Matching Type Flow Analysis

Pattern matching is based on Type Flow Analysis technology, automatically binding variables to the target type in branches where the instanceof check is true.

**Traditional vs Pattern Matching**:

```java
// Traditional way: Two-step operation
if (obj instanceof String) {
    String s = (String) obj;  // Explicit cast needed
    System.out.println(s.length());
}

// Pattern matching: One step
if (obj instanceof String s) {  // Type check + variable binding
    System.out.println(s.length());  // s is already String type
}
```

**Scope Rules**: Pattern variables are only valid within the scope where type check is true.

### Records Compiler Magic

Record classes have the following members automatically generated by the compiler:

```java
public record Point(int x, int y) {}

// Compiler automatically generates:
// 1. private final fields: x, y
// 2. Canonical constructor: public Point(int x, int y)
// 3. Accessor methods: public int x(), public int y()
// 4. equals(Object o): Value comparison based on all components
// 5. hashCode(): Hash calculation based on all components
// 6. toString(): Returns "Point[x=..., y=...]"
```

### Text Blocks Processing Flow

Text blocks go through three processing phases at compile time:

1. **Line Terminator Normalization**: All line terminators converted to LF (\n)
2. **Incidental White Space Removal**: Remove common leading whitespace from each line
3. **Escape Sequence Interpretation**: Process escape characters

```java
String html = """
              <html>
                  <body>
                      <p>Hello</p>
                  </body>
              </html>
              """;
// Closing delimiter position determines incidental whitespace removal amount
```

### Switch Expression Evaluation Semantics

Switch expressions have the following characteristics:

- **Expression Semantics**: switch can return values
- **Arrow Labels**: Use `->` to avoid fall-through
- **yield Statement**: Return values within code blocks
- **Exhaustiveness Check**: Must cover all possible cases

## Key Points

### Sealed Classes

| Keyword | Purpose | Usage Location |
|---------|---------|----------------|
| `sealed` | Declare sealed type | Class/interface declaration |
| `permits` | Specify allowed subclasses | Sealed type declaration |
| `final` | Prohibit further inheritance | Subclass declaration |
| `non-sealed` | Open inheritance restriction | Subclass declaration |

**Core Rules**:
- Subclasses of sealed classes must be `final`, `sealed`, or `non-sealed`
- Subclasses must be in the same module (or same package if unnamed module) as the sealed class
- permits clause can be omitted (when subclasses are declared in the same file)

### Pattern Matching for instanceof

**Pattern Variable Scope**:

```java
// Available after &&
if (obj instanceof String s && s.length() > 5) { }

// Not available after || (compile error)
// if (obj instanceof String s || s.isEmpty()) { }  // Error!

// Available after negation in else branch
if (!(obj instanceof String s)) {
    return;
}
// s is available here (because if not String, already returned)
s.toUpperCase();
```

### Records

**What Records Can Do**:
- Define components (automatically generate fields and accessors)
- Implement interfaces
- Define static fields and static methods
- Define instance methods
- Customize canonical constructor and compact constructor
- Add other constructors (must delegate to canonical constructor)

**What Records Cannot Do**:
- Extend other classes (implicitly extends java.lang.Record)
- Be extended by other classes (implicitly final)
- Declare instance fields (except components)
- Be abstract

### Text Blocks

**New Escape Sequences**:
- `\<line-terminator>`: Line terminator, does not produce newline
- `\s`: Single space, preserves trailing whitespace

```java
// Use \ to avoid newline
String singleLine = """
    This is a very long string, \
    but it's actually just one line\
    """;

// Use \s to preserve trailing whitespace
String withTrailingSpace = """
    Line one   \s
    Line two   \s
    """;
```

### Switch Expressions

**Syntax Form Comparison**:

| Form | Fall-through Behavior | Return Value |
|------|----------------------|--------------|
| `case L:` | Falls through | None |
| `case L ->` | No fall-through | Optional |
| `yield value;` | - | Returns in block |

## Code Examples

### Example 1: Sealed Classes Implementing Shape Hierarchy

```java
/**
 * Using sealed classes to define a complete shape type hierarchy
 * Demonstrates sealed class declaration, inheritance constraints, and pattern matching
 */

// Sealed interface defining allowed implementation types
public sealed interface Shape permits Circle, Rectangle, Triangle {
    double area();
    double perimeter();
    String describe();
}

// final implementation class - cannot be inherited
public final class Circle implements Shape {
    private final double radius;

    public Circle(double radius) {
        if (radius <= 0) {
            throw new IllegalArgumentException("Radius must be positive: " + radius);
        }
        this.radius = radius;
    }

    public double radius() {
        return radius;
    }

    @Override
    public double area() {
        return Math.PI * radius * radius;
    }

    @Override
    public double perimeter() {
        return 2 * Math.PI * radius;
    }

    @Override
    public String describe() {
        return String.format("Circle [radius=%.2f, area=%.2f]", radius, area());
    }
}

// final implementation class - cannot be inherited
public final class Rectangle implements Shape {
    private final double width;
    private final double height;

    public Rectangle(double width, double height) {
        if (width <= 0 || height <= 0) {
            throw new IllegalArgumentException("Width and height must be positive");
        }
        this.width = width;
        this.height = height;
    }

    public double width() { return width; }
    public double height() { return height; }
    public boolean isSquare() { return width == height; }

    @Override
    public double area() {
        return width * height;
    }

    @Override
    public double perimeter() {
        return 2 * (width + height);
    }

    @Override
    public String describe() {
        String type = isSquare() ? "Square" : "Rectangle";
        return String.format("%s [width=%.2f, height=%.2f, area=%.2f]",
            type, width, height, area());
    }
}

// non-sealed implementation class - open for inheritance
public non-sealed class Triangle implements Shape {
    protected final double a, b, c;

    public Triangle(double a, double b, double c) {
        if (a <= 0 || b <= 0 || c <= 0) {
            throw new IllegalArgumentException("Side lengths must be positive");
        }
        if (!isValidTriangle(a, b, c)) {
            throw new IllegalArgumentException("Does not satisfy triangle inequality");
        }
        this.a = a;
        this.b = b;
        this.c = c;
    }

    private static boolean isValidTriangle(double a, double b, double c) {
        return a + b > c && b + c > a && a + c > b;
    }

    @Override
    public double area() {
        double s = perimeter() / 2;
        return Math.sqrt(s * (s - a) * (s - b) * (s - c));
    }

    @Override
    public double perimeter() {
        return a + b + c;
    }

    @Override
    public String describe() {
        return String.format("Triangle [sides=%.2f,%.2f,%.2f, area=%.2f]",
            a, b, c, area());
    }
}

// Equilateral triangle - inherits from non-sealed Triangle
public class EquilateralTriangle extends Triangle {
    public EquilateralTriangle(double side) {
        super(side, side, side);
    }

    @Override
    public String describe() {
        return String.format("Equilateral Triangle [side=%.2f, area=%.2f]", a, area());
    }
}

// Shape processor utility class
public class ShapeProcessor {

    /**
     * Using switch expression to handle sealed class hierarchy
     * Compiler ensures exhaustiveness check, no default branch needed
     */
    public static String classify(Shape shape) {
        return switch (shape) {
            case Circle c -> "Circle, radius " + c.radius();
            case Rectangle r when r.isSquare() -> "Square, side " + r.width();
            case Rectangle r -> "Rectangle, dimensions " + r.width() + "x" + r.height();
            case Triangle t -> "Triangle, perimeter " + t.perimeter();
        };
    }

    /**
     * Calculate total area of shape array
     */
    public static double totalArea(Shape... shapes) {
        double total = 0;
        for (Shape shape : shapes) {
            total += switch (shape) {
                case Circle c -> c.area();
                case Rectangle r -> r.area();
                case Triangle t -> t.area();
            };
        }
        return total;
    }

    public static void main(String[] args) {
        Shape[] shapes = {
            new Circle(5),
            new Rectangle(4, 6),
            new Rectangle(5, 5),
            new Triangle(3, 4, 5),
            new EquilateralTriangle(6)
        };

        System.out.println("=== Shape Classification ===");
        for (Shape shape : shapes) {
            System.out.println(classify(shape));
            System.out.println("  Details: " + shape.describe());
        }

        System.out.println("\nTotal Area: " + String.format("%.2f", totalArea(shapes)));
    }
}
```

### Example 2: Pattern Matching for Type-Safe Data Processing

```java
import java.time.LocalDate;
import java.util.*;

/**
 * Demonstrates various use cases of Pattern Matching for instanceof
 */
public class PatternMatchingDemo {

    // Simulate different types of database query results
    sealed interface QueryResult permits
        SingleResult, MultipleResults, EmptyResult, ErrorResult {
    }

    record SingleResult(Object value) implements QueryResult {}
    record MultipleResults(List<Object> values) implements QueryResult {}
    record EmptyResult() implements QueryResult {}
    record ErrorResult(String message, Exception cause) implements QueryResult {}

    /**
     * Basic pattern matching: Type check + variable binding
     */
    public static String formatValue(Object value) {
        if (value instanceof String s) {
            return "String: \"" + s + "\" (length=" + s.length() + ")";
        } else if (value instanceof Integer i) {
            return "Integer: " + i + " (hex=0x" + Integer.toHexString(i) + ")";
        } else if (value instanceof Double d) {
            return String.format("Double: %.4f", d);
        } else if (value instanceof LocalDate date) {
            return "Date: " + date.getYear() + "-" +
                   date.getMonthValue() + "-" + date.getDayOfMonth();
        } else if (value instanceof List<?> list) {
            return "List: " + list.size() + " elements";
        } else if (value instanceof Map<?, ?> map) {
            return "Map: " + map.size() + " key-value pairs";
        } else if (value == null) {
            return "Null";
        }
        return "Unknown type: " + value.getClass().getSimpleName();
    }

    /**
     * Pattern matching combined with conditions
     */
    public static String categorizeNumber(Object obj) {
        // Pattern matching can be combined with &&
        if (obj instanceof Integer i && i > 0) {
            if (i < 10) return "Small positive integer";
            if (i < 100) return "Medium positive integer";
            return "Large positive integer";
        }
        if (obj instanceof Integer i && i < 0) {
            return "Negative integer";
        }
        if (obj instanceof Integer i && i == 0) {
            return "Zero";
        }
        if (obj instanceof Double d && !d.isNaN() && !d.isInfinite()) {
            return "Finite floating point";
        }
        if (obj instanceof Number) {
            return "Other numeric type";
        }
        return "Non-numeric type";
    }

    /**
     * Pattern variable scope - usage after negation
     */
    public static String processInput(Object input) {
        // Return early if not a string
        if (!(input instanceof String s)) {
            return "Input must be a string";
        }

        // Here, s is already String type (because non-String case already returned)
        // Compiler determines s's availability through data flow analysis
        if (s.isBlank()) {
            return "Input cannot be blank";
        }

        return "Result: " + s.trim().toUpperCase();
    }

    /**
     * Type-safe implementation for processing query results
     */
    public static void handleQueryResult(QueryResult result) {
        if (result instanceof SingleResult sr) {
            System.out.println("Single result: " + formatValue(sr.value()));
        } else if (result instanceof MultipleResults mr && !mr.values().isEmpty()) {
            System.out.println("Multiple results (" + mr.values().size() + " items):");
            mr.values().forEach(v -> System.out.println("  - " + formatValue(v)));
        } else if (result instanceof MultipleResults mr) {
            System.out.println("Query returned empty list");
        } else if (result instanceof EmptyResult) {
            System.out.println("No matching results");
        } else if (result instanceof ErrorResult err) {
            System.err.println("Query error: " + err.message());
            if (err.cause() != null) {
                System.err.println("Cause: " + err.cause().getMessage());
            }
        }
    }

    /**
     * Recursive pattern matching for complex objects
     */
    public static int calculateDepth(Object obj) {
        if (obj instanceof List<?> list && !list.isEmpty()) {
            int maxDepth = 0;
            for (Object item : list) {
                maxDepth = Math.max(maxDepth, calculateDepth(item));
            }
            return 1 + maxDepth;
        }
        if (obj instanceof Map<?, ?> map && !map.isEmpty()) {
            int maxDepth = 0;
            for (Object value : map.values()) {
                maxDepth = Math.max(maxDepth, calculateDepth(value));
            }
            return 1 + maxDepth;
        }
        return 0;
    }

    public static void main(String[] args) {
        // Test basic type formatting
        System.out.println("=== Value Formatting Test ===");
        Object[] values = {
            "Hello, World",
            42,
            3.14159265,
            LocalDate.of(2024, 1, 15),
            List.of(1, 2, 3),
            Map.of("a", 1, "b", 2),
            null
        };

        for (Object value : values) {
            System.out.println(formatValue(value));
        }

        // Test number categorization
        System.out.println("\n=== Number Categorization Test ===");
        Object[] numbers = {5, 50, 500, -10, 0, 3.14, Double.NaN, "not a number"};
        for (Object num : numbers) {
            System.out.println(num + " -> " + categorizeNumber(num));
        }

        // Test query result processing
        System.out.println("\n=== Query Result Processing Test ===");
        QueryResult[] results = {
            new SingleResult("User John"),
            new MultipleResults(List.of("Order1", "Order2", "Order3")),
            new MultipleResults(List.of()),
            new EmptyResult(),
            new ErrorResult("Connection timeout", new RuntimeException("Network unreachable"))
        };

        for (QueryResult result : results) {
            handleQueryResult(result);
        }

        // Test nested depth calculation
        System.out.println("\n=== Nested Depth Calculation ===");
        Object nested = List.of(
            1,
            List.of(2, 3),
            List.of(List.of(4, 5), List.of(6))
        );
        System.out.println("Nesting depth: " + calculateDepth(nested));
    }
}
```

### Example 3: Records Building Domain Models

```java
import java.math.BigDecimal;
import java.math.RoundingMode;
import java.time.LocalDateTime;
import java.util.*;
import java.util.stream.Collectors;

/**
 * Using Records to build e-commerce domain model
 * Demonstrates various advanced usages of Records
 */

// Value object: Money
public record Money(BigDecimal amount, String currency) {

    // Compact constructor for validation and normalization
    public Money {
        Objects.requireNonNull(amount, "Amount cannot be null");
        Objects.requireNonNull(currency, "Currency code cannot be null");

        if (amount.compareTo(BigDecimal.ZERO) < 0) {
            throw new IllegalArgumentException("Amount cannot be negative: " + amount);
        }

        currency = currency.toUpperCase();
        amount = amount.setScale(2, RoundingMode.HALF_UP);
    }

    // Static factory methods
    public static Money of(double amount, String currency) {
        return new Money(BigDecimal.valueOf(amount), currency);
    }

    public static Money cny(double amount) {
        return of(amount, "CNY");
    }

    public static Money usd(double amount) {
        return of(amount, "USD");
    }

    public static final Money ZERO_CNY = cny(0);
    public static final Money ZERO_USD = usd(0);

    // Money operations
    public Money add(Money other) {
        validateSameCurrency(other);
        return new Money(amount.add(other.amount), currency);
    }

    public Money subtract(Money other) {
        validateSameCurrency(other);
        return new Money(amount.subtract(other.amount), currency);
    }

    public Money multiply(int quantity) {
        return new Money(amount.multiply(BigDecimal.valueOf(quantity)), currency);
    }

    public Money multiply(BigDecimal factor) {
        return new Money(amount.multiply(factor), currency);
    }

    private void validateSameCurrency(Money other) {
        if (!currency.equals(other.currency)) {
            throw new IllegalArgumentException(
                "Currency mismatch: " + currency + " vs " + other.currency);
        }
    }

    // Comparison methods
    public boolean isGreaterThan(Money other) {
        validateSameCurrency(other);
        return amount.compareTo(other.amount) > 0;
    }

    public boolean isLessThan(Money other) {
        validateSameCurrency(other);
        return amount.compareTo(other.amount) < 0;
    }

    public String formatted() {
        return switch (currency) {
            case "CNY" -> "CN\u00A5" + amount;
            case "USD" -> "$" + amount;
            case "EUR" -> "\u20AC" + amount;
            default -> amount + " " + currency;
        };
    }
}

// Value object: Address
public record Address(
    String province,
    String city,
    String district,
    String street,
    String zipCode
) {
    public Address {
        Objects.requireNonNull(province, "Province cannot be null");
        Objects.requireNonNull(city, "City cannot be null");
        Objects.requireNonNull(district, "District cannot be null");
        Objects.requireNonNull(street, "Street address cannot be null");

        province = province.trim();
        city = city.trim();
        district = district.trim();
        street = street.trim();

        if (zipCode != null) {
            zipCode = zipCode.trim();
        }
    }

    public String fullAddress() {
        return province + ", " + city + ", " + district + ", " + street;
    }
}

// Entity: Product
public record Product(
    String id,
    String name,
    String description,
    Money price,
    int stock,
    String category
) {
    public Product {
        Objects.requireNonNull(id, "Product ID cannot be null");
        Objects.requireNonNull(name, "Product name cannot be null");
        Objects.requireNonNull(price, "Product price cannot be null");

        if (stock < 0) {
            throw new IllegalArgumentException("Stock cannot be negative");
        }
    }

    public boolean isAvailable() {
        return stock > 0;
    }

    public Product withStock(int newStock) {
        return new Product(id, name, description, price, newStock, category);
    }

    public Product reduceStock(int quantity) {
        if (quantity > stock) {
            throw new IllegalStateException("Insufficient stock");
        }
        return withStock(stock - quantity);
    }
}

// Value object: Order Item
public record OrderItem(Product product, int quantity) {

    public OrderItem {
        Objects.requireNonNull(product, "Product cannot be null");
        if (quantity <= 0) {
            throw new IllegalArgumentException("Quantity must be greater than 0");
        }
    }

    public Money subtotal() {
        return product.price().multiply(quantity);
    }
}

// Order status
public enum OrderStatus {
    PENDING("Pending Payment"),
    PAID("Paid"),
    SHIPPED("Shipped"),
    DELIVERED("Delivered"),
    CANCELLED("Cancelled");

    private final String displayName;

    OrderStatus(String displayName) {
        this.displayName = displayName;
    }

    public String displayName() {
        return displayName;
    }
}

// Aggregate root: Order
public record Order(
    String orderId,
    String customerId,
    List<OrderItem> items,
    Address shippingAddress,
    OrderStatus status,
    LocalDateTime createdAt,
    LocalDateTime updatedAt
) {
    public Order {
        Objects.requireNonNull(orderId);
        Objects.requireNonNull(customerId);
        Objects.requireNonNull(shippingAddress);
        Objects.requireNonNull(status);

        items = items != null ? List.copyOf(items) : List.of();

        if (items.isEmpty() && status != OrderStatus.CANCELLED) {
            throw new IllegalArgumentException("Order must contain at least one item");
        }

        if (createdAt == null) {
            createdAt = LocalDateTime.now();
        }
        if (updatedAt == null) {
            updatedAt = createdAt;
        }
    }

    // Static factory method
    public static Order create(
        String customerId,
        List<OrderItem> items,
        Address shippingAddress
    ) {
        String orderId = "ORD-" + System.currentTimeMillis();
        return new Order(
            orderId,
            customerId,
            items,
            shippingAddress,
            OrderStatus.PENDING,
            null,
            null
        );
    }

    // Calculate total amount
    public Money totalAmount() {
        return items.stream()
            .map(OrderItem::subtotal)
            .reduce(Money.ZERO_CNY, Money::add);
    }

    // Get item count
    public int totalItems() {
        return items.stream()
            .mapToInt(OrderItem::quantity)
            .sum();
    }

    // State transition methods
    public Order pay() {
        if (status != OrderStatus.PENDING) {
            throw new IllegalStateException("Only pending orders can be paid");
        }
        return withStatus(OrderStatus.PAID);
    }

    public Order ship() {
        if (status != OrderStatus.PAID) {
            throw new IllegalStateException("Only paid orders can be shipped");
        }
        return withStatus(OrderStatus.SHIPPED);
    }

    public Order deliver() {
        if (status != OrderStatus.SHIPPED) {
            throw new IllegalStateException("Only shipped orders can be delivered");
        }
        return withStatus(OrderStatus.DELIVERED);
    }

    public Order cancel() {
        if (status == OrderStatus.DELIVERED) {
            throw new IllegalStateException("Delivered orders cannot be cancelled");
        }
        return withStatus(OrderStatus.CANCELLED);
    }

    private Order withStatus(OrderStatus newStatus) {
        return new Order(
            orderId, customerId, items, shippingAddress,
            newStatus, createdAt, LocalDateTime.now()
        );
    }

    // Formatted output
    public String summary() {
        return String.format(
            "Order %s [%s] - %d items, total %s",
            orderId, status.displayName(), totalItems(), totalAmount().formatted()
        );
    }
}
```

```java
public class SwitchExpressionsDemo {

            case SATURDAY, SUNDAY -> "Weekend";

    public static int getDayNumber(DayOfWeek day) {
        return switch (day) {
            case MONDAY -> 1;
            case TUESDAY -> 2;
            case WEDNESDAY -> 3;
            case THURSDAY -> 4;
            case FRIDAY -> 5;
            case SATURDAY -> {
                System.out.println("Saturday rest");

            }
            case SUNDAY -> {
                System.out.println("Sunday rest");

            }
        };
    }

    // Using switch expression with enums
    public enum TrafficLight {
        RED, YELLOW, GREEN
    }

        return switch (light) {
            case RED -> "Stop";
            case YELLOW -> "Slow down";

    public enum OrderStatus {
        CREATED, PENDING_PAYMENT, PAID, PROCESSING, SHIPPED, DELIVERED, CANCELLED, REFUNDED

    public static OrderAction processOrderStatus(OrderStatus status, boolean hasPaymentIssue) {
        return switch (status) {
            case CREATED -> new OrderAction(
                "await_payment",
                "Waiting for user payment",
                false
            );

            case PENDING_PAYMENT -> {
                if (hasPaymentIssue) {
                    yield new OrderAction(
                        "retry_payment",
                        "Payment issue encountered, please retry",
                        true
                    );
                }
                yield new OrderAction(
                    "processing_payment",
                    "Payment processing",
                    false
                );
            }

            case PAID -> new OrderAction(
                "start_processing",
                "Payment successful, starting order processing",
                true
            );

            case PROCESSING -> new OrderAction(
                "prepare_shipment",
                "Order processing, preparing shipment",
                false
            );

            case SHIPPED -> new OrderAction(
                "track_delivery",
                "Order shipped, tracking available",
                true
            );

            case DELIVERED -> new OrderAction(
                "confirm_receipt",
                "Order delivered, please confirm receipt",
                true
            );

            case CANCELLED -> new OrderAction(

                "Order cancelled, processing refund",
                true
            );

            case REFUNDED -> new OrderAction(
                "close_order",
                "Refund complete, order closed",
                true
            );
        };
    }

    // Using switch expression to calculate results
    public static double calculateDiscount(String customerLevel, double amount) {
        double discountRate = switch (customerLevel.toUpperCase()) {
            case "BRONZE" -> 0.0;
            case "SILVER" -> 0.05;
            case "GOLD" -> 0.10;
            case "PLATINUM" -> 0.15;
            case "DIAMOND" -> 0.20;
            default -> {
                System.out.println("Unknown membership level: " + customerLevel);
                yield 0.0;

        return switch (operator) {

            case "-" -> a - b;
            case "*" -> a * b;
            case "/" -> {
                if (b == 0) {
                    throw new ArithmeticException("Division by zero");
                }
                yield a / b;
```

## Best Practices

### Sealed Classes Best Practices

1. **Use for modeling finite type hierarchies**
```java
// Good: Types are finite and fixed
public sealed interface PaymentMethod permits
    CreditCard, DebitCard, BankTransfer, DigitalWallet {}

// Avoid: Scenarios where types might expand infinitely
// sealed interface Animal permits Cat, Dog, ...  // Not suitable
```

2. **Use with Records**
```java
public sealed interface Result<T> permits Success, Failure {
    <R> R fold(Function<T, R> onSuccess, Function<String, R> onFailure);
}

public record Success<T>(T value) implements Result<T> {
    @Override
    public <R> R fold(Function<T, R> onSuccess, Function<String, R> onFailure) {
        return onSuccess.apply(value);
    }
}

public record Failure<T>(String error) implements Result<T> {
    @Override
    public <R> R fold(Function<T, R> onSuccess, Function<String, R> onFailure) {
        return onFailure.apply(error);
    }
}
```

3. **Leverage compiler exhaustiveness checking**
```java
// Compiler ensures all cases are handled, no default needed
public static double calculateArea(Shape shape) {
    return switch (shape) {
        case Circle c -> Math.PI * c.radius() * c.radius();
        case Rectangle r -> r.width() * r.height();
        case Triangle t -> calculateTriangleArea(t);
    };
}
```

```java
    if (s.isBlank()) {
```

## Common Pitfalls

### Sealed Classes Pitfalls

1. **Forgetting to declare final/sealed/non-sealed on subclasses**
```java
public sealed interface Vehicle permits Car, Truck {}

// Error: Missing modifier
// public class Car implements Vehicle {}  // Compile error

// Correct
public final class Car implements Vehicle {}
public sealed class Truck implements Vehicle permits PickupTruck, SemiTruck {}
public non-sealed class PickupTruck extends Truck {}
```

### Pattern Matching Pitfalls

1. **Misunderstanding pattern variable scope**
```java
// Error: s not available after ||
// if (obj instanceof String s || s.isEmpty()) { }

// Correct: Use && or refactor logic
if (obj instanceof String s && !s.isEmpty()) {
    // s is available
}
```

### Records Pitfalls

1. **Mutable objects as components**
```java
// Problem: Component is mutable
public record BadExample(List<String> items, Date date) {}

var list = new ArrayList<String>();
list.add("item1");
var record = new BadExample(list, new Date());

list.add("item2");  // Modified the list inside record!

// Solution: Create immutable copy in constructor
public record GoodExample(List<String> items, Date date) {
    public GoodExample {
        items = List.copyOf(items);
        date = new Date(date.getTime());
    }

    @Override
    public Date date() {
        return new Date(date.getTime());  // Return copy
    }
}
```

### Switch Expressions Pitfalls

1. **Mixing arrow and colon labels**
```java
// Error: Cannot mix
// String result = switch (x) {
//     case 1 -> "one";
//     case 2: yield "two";  // Compile error
// };

// Correct: Use one style consistently
String result = switch (x) {
    case 1 -> "one";
    case 2 -> "two";
    default -> "other";
};
```

2. **Forgetting yield or using return**
```java
// Error: Using return in switch expression code block
// String result = switch (x) {
//     case 1 -> {
//         return "one";  // Compile error
//     }
//     default -> "other";
// };

// Correct: Use yield
String result = switch (x) {
    case 1 -> {
        // Complex logic
        yield "one";
    }
    default -> "other";
};
```

## Interview Key Points

### High-Frequency Interview Questions

**1. What's the difference between sealed classes, final classes, and abstract classes?**

| Feature | final class | abstract class | sealed class |
|---------|-------------|----------------|--------------|
| Can be inherited | No | Yes (unlimited) | Yes (restricted) |
| Can be instantiated | Yes | No | Depends on abstract |
| Exhaustiveness check | Not meaningful | Not supported | Supported |
| Use case | Prevent inheritance | Template pattern | Controlled type hierarchy |

**2. What are the scope rules in pattern matching?**

- Pattern variables are valid in branches where instanceof returns true
- Can be combined with `&&` (valid in right-side expression)
- Cannot be combined with `||` (because left side may short-circuit)
- After negation, if subsequent code must execute, variable is also valid

**3. Can Records be inherited? Why?**

No. Records are implicitly final because:
- Records' semantics are data carriers, their equivalence is based on all components
- If inheritance were allowed, subclasses could add new components, breaking equivalence semantics
- Immutability guarantees would also be broken

**4. What's the difference between text blocks and string concatenation?**

- **Compile-time processing**: Text blocks are processed at compile time, becoming regular strings at runtime
- **Whitespace handling**: Automatically removes incidental whitespace (common leading whitespace)
- **Readability**: Multi-line text is clearer
- **Performance**: No runtime concatenation overhead

**5. What's the difference between yield and return in switch expressions?**

- `yield` is used to return a value from a code block in a switch expression
- `return` is used to return from a method
- In switch expression code blocks, must use `yield`, cannot use `return`

## Summary

Java 17 as an important LTS version introduces several features that change how we program in Java:

1. **Sealed Classes**: Provide precise control over class inheritance hierarchy, combined with pattern matching for type-safe polymorphic processing

2. **Pattern Matching**: Simplifies type checking and casting code, eliminates redundant explicit casts

3. **Records**: Provide concise syntax for immutable data classes, reducing boilerplate code

4. **Text Blocks**: Improve multi-line string handling, especially suitable for HTML, JSON, SQL scenarios

5. **Switch Expressions**: Enhance switch's expressiveness, supporting return values and exhaustiveness checking

These features work together to make Java code more concise, safe, and maintainable. Developers are recommended to:

- Actively adopt these features in new projects
- When upgrading existing projects to Java 17, gradually refactor code to leverage new features
- Pay attention to Java's continuous evolution, such as Virtual Threads and Record Patterns in Java 21

Mastering Java 17's new features is an essential skill for becoming a modern Java developer.
