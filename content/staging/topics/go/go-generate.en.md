`go generate` is a built-in Go tool that automates code generation by scanning source files for special comments and running specified commands. It's used to generate boilerplate code, create type-safe wrappers, implement interfaces, and more.

## Concept Explanation

`go generate` scans Go source files for directives of the form:

```go
//go:generate command arguments...
```

When you run `go generate`, it executes these commands in the package directory. The generated code becomes part of your codebase and is committed to version control.

Common use cases:
- Generating string methods for enums
- Creating mock implementations
- Building protocol buffers
- Generating SQL migrations
- Creating asset embeddings

```go
package main

//go:generate stringer -type=Status

type Status int

const (
    Pending Status = iota
    Active
    Completed
    Cancelled
)

func main() {
    s := Active
    println(s.String()) // "Active" - method generated by stringer
}
```

## Core Principles

### Directive Syntax

```go
package example

// Basic directive
//go:generate echo "Hello, World!"

// Multiple arguments
//go:generate stringer -type=MyType -output=mytype_string.go

// Using environment variables
//go:generate sh -c "echo $GOFILE"

// Chaining commands
//go:generate sh -c "cmd1 && cmd2"

// Long commands with line continuation (NOT supported - use sh -c instead)
//go:generate sh -c "long-command --flag1 --flag2 --flag3"
```

### Built-in Variables

```go
package example

// $GOARCH - target architecture
// $GOOS - target operating system
// $GOFILE - current file name
// $GOLINE - line number of the directive
// $GOPACKAGE - package name
// $DOLLAR - literal dollar sign

//go:generate echo "File: $GOFILE"
//go:generate echo "Package: $GOPACKAGE"
//go:generate echo "OS: $GOOS, Arch: $GOARCH"
```

### Running go generate

```bash
# Generate for current package
go generate

# Generate for specific package
go generate ./pkg/models

# Generate for all packages
go generate ./...

# Verbose output
go generate -v ./...

# Dry run (show commands without executing)
go generate -n ./...

# Run specific generator
go generate -run "stringer" ./...
```

## Key Concepts

### Stringer - Enum String Methods

The `stringer` tool generates `String()` methods for integer constants:

```go
// file: status.go
package order

//go:generate stringer -type=Status

type Status int

const (
    StatusPending Status = iota
    StatusProcessing
    StatusShipped
    StatusDelivered
    StatusCancelled
)

// After running go generate, status_string.go is created with:
// func (s Status) String() string { ... }
```

Install stringer: `go install golang.org/x/tools/cmd/stringer@latest`

### Mockgen - Mock Generation

Generate mock implementations for testing:

```go
// file: repository.go
package user

//go:generate mockgen -source=repository.go -destination=mocks/mock_repository.go -package=mocks

type Repository interface {
    GetByID(id int64) (*User, error)
    Create(user *User) error
    Update(user *User) error
    Delete(id int64) error
    List(offset, limit int) ([]*User, error)
}

type User struct {
    ID    int64
    Name  string
    Email string
}
```

Install mockgen: `go install github.com/golang/mock/mockgen@latest`

Usage in tests:

```go
// file: service_test.go
package user_test

import (
    "testing"

    "github.com/golang/mock/gomock"
    "myapp/user"
    "myapp/user/mocks"
)

func TestUserService_GetUser(t *testing.T) {
    ctrl := gomock.NewController(t)
    defer ctrl.Finish()

    mockRepo := mocks.NewMockRepository(ctrl)

    // Setup expectations
    mockRepo.EXPECT().
        GetByID(int64(1)).
        Return(&user.User{ID: 1, Name: "Alice"}, nil)

    service := user.NewService(mockRepo)
    u, err := service.GetUser(1)

    if err != nil {
        t.Fatalf("unexpected error: %v", err)
    }
    if u.Name != "Alice" {
        t.Errorf("expected Alice, got %s", u.Name)
    }
}
```

## Code Examples

### Custom Code Generator

Create your own code generator:

```go
// file: cmd/enumgen/main.go
package main

import (
    "bytes"
    "flag"
    "fmt"
    "go/ast"
    "go/parser"
    "go/token"
    "os"
    "strings"
    "text/template"
)

var (
    typeName   = flag.String("type", "", "type name")
    outputFile = flag.String("output", "", "output file name")
)

const tmpl = `// Code generated by enumgen. DO NOT EDIT.
package {{.Package}}

import "fmt"

var _{{.Type}}Names = map[{{.Type}}]string{
{{- range .Values}}
    {{.Name}}: "{{.Name}}",
{{- end}}
}

var _{{.Type}}Values = map[string]{{.Type}}{
{{- range .Values}}
    "{{.Name}}": {{.Name}},
{{- end}}
}

func (e {{.Type}}) String() string {
    if name, ok := _{{.Type}}Names[e]; ok {
        return name
    }
    return fmt.Sprintf("{{.Type}}(%d)", e)
}

func Parse{{.Type}}(s string) ({{.Type}}, error) {
    if v, ok := _{{.Type}}Values[s]; ok {
        return v, nil
    }
    return 0, fmt.Errorf("invalid {{.Type}}: %s", s)
}

func (e {{.Type}}) MarshalText() ([]byte, error) {
    return []byte(e.String()), nil
}

func (e *{{.Type}}) UnmarshalText(text []byte) error {
    v, err := Parse{{.Type}}(string(text))
    if err != nil {
        return err
    }
    *e = v
    return nil
}
`

type Value struct {
    Name string
}

type TemplateData struct {
    Package string
    Type    string
    Values  []Value
}

func main() {
    flag.Parse()

    if *typeName == "" {
        fmt.Fprintln(os.Stderr, "type name required")
        os.Exit(1)
    }

    // Parse source file
    filename := os.Getenv("GOFILE")
    fset := token.NewFileSet()
    f, err := parser.ParseFile(fset, filename, nil, parser.ParseComments)
    if err != nil {
        fmt.Fprintf(os.Stderr, "parse error: %v\n", err)
        os.Exit(1)
    }

    // Find constants of the specified type
    var values []Value
    ast.Inspect(f, func(n ast.Node) bool {
        decl, ok := n.(*ast.GenDecl)
        if !ok || decl.Tok != token.CONST {
            return true
        }

        for _, spec := range decl.Specs {
            vspec, ok := spec.(*ast.ValueSpec)
            if !ok {
                continue
            }

            // Check if type matches
            if vspec.Type != nil {
                ident, ok := vspec.Type.(*ast.Ident)
                if !ok || ident.Name != *typeName {
                    continue
                }
            }

            for _, name := range vspec.Names {
                if !strings.HasPrefix(name.Name, "_") {
                    values = append(values, Value{Name: name.Name})
                }
            }
        }
        return true
    })

    // Generate code
    data := TemplateData{
        Package: f.Name.Name,
        Type:    *typeName,
        Values:  values,
    }

    t := template.Must(template.New("enum").Parse(tmpl))
    var buf bytes.Buffer
    if err := t.Execute(&buf, data); err != nil {
        fmt.Fprintf(os.Stderr, "template error: %v\n", err)
        os.Exit(1)
    }

    // Write output
    output := *outputFile
    if output == "" {
        output = strings.ToLower(*typeName) + "_enum.go"
    }

    if err := os.WriteFile(output, buf.Bytes(), 0644); err != nil {
        fmt.Fprintf(os.Stderr, "write error: %v\n", err)
        os.Exit(1)
    }

    fmt.Printf("Generated %s\n", output)
}
```

### SQL Query Generator

```go
// file: cmd/sqlgen/main.go
package main

import (
    "flag"
    "fmt"
    "os"
    "strings"
    "text/template"
)

var (
    tableName = flag.String("table", "", "database table name")
    modelType = flag.String("type", "", "model struct type")
    output    = flag.String("output", "", "output file")
)

const queryTemplate = `// Code generated by sqlgen. DO NOT EDIT.
package {{.Package}}

const (
    {{.Type}}TableName = "{{.Table}}"

    {{.Type}}SelectAll = ` + "`" + `
        SELECT {{.Columns}}
        FROM {{.Table}}
    ` + "`" + `

    {{.Type}}SelectByID = ` + "`" + `
        SELECT {{.Columns}}
        FROM {{.Table}}
        WHERE id = $1
    ` + "`" + `

    {{.Type}}Insert = ` + "`" + `
        INSERT INTO {{.Table}} ({{.InsertColumns}})
        VALUES ({{.InsertPlaceholders}})
        RETURNING id
    ` + "`" + `

    {{.Type}}Update = ` + "`" + `
        UPDATE {{.Table}}
        SET {{.UpdateSet}}
        WHERE id = $1
    ` + "`" + `

    {{.Type}}Delete = ` + "`" + `
        DELETE FROM {{.Table}}
        WHERE id = $1
    ` + "`" + `
)
`

type Field struct {
    Name   string
    Column string
}

func main() {
    flag.Parse()

    // In a real implementation, parse the struct to get fields
    // This is simplified for demonstration
    fields := []Field{
        {Name: "ID", Column: "id"},
        {Name: "Name", Column: "name"},
        {Name: "Email", Column: "email"},
        {Name: "CreatedAt", Column: "created_at"},
    }

    var columns, insertColumns []string
    var placeholders, updateSet []string

    for i, f := range fields {
        columns = append(columns, f.Column)
        if f.Column != "id" {
            insertColumns = append(insertColumns, f.Column)
            placeholders = append(placeholders, fmt.Sprintf("$%d", len(insertColumns)))
            updateSet = append(updateSet,
                fmt.Sprintf("%s = $%d", f.Column, i+1))
        }
    }

    data := struct {
        Package            string
        Type               string
        Table              string
        Columns            string
        InsertColumns      string
        InsertPlaceholders string
        UpdateSet          string
    }{
        Package:            os.Getenv("GOPACKAGE"),
        Type:               *modelType,
        Table:              *tableName,
        Columns:            strings.Join(columns, ", "),
        InsertColumns:      strings.Join(insertColumns, ", "),
        InsertPlaceholders: strings.Join(placeholders, ", "),
        UpdateSet:          strings.Join(updateSet, ", "),
    }

    t := template.Must(template.New("sql").Parse(queryTemplate))

    outFile := *output
    if outFile == "" {
        outFile = strings.ToLower(*modelType) + "_queries.go"
    }

    f, _ := os.Create(outFile)
    defer f.Close()

    t.Execute(f, data)
}
```

### Asset Embedding Generator

```go
// file: cmd/embedgen/main.go
package main

import (
    "encoding/base64"
    "flag"
    "fmt"
    "io/ioutil"
    "os"
    "path/filepath"
    "strings"
    "text/template"
)

var (
    dir        = flag.String("dir", "", "directory to embed")
    pkgName    = flag.String("package", "", "package name")
    outputFile = flag.String("output", "assets.go", "output file")
)

const assetTemplate = `// Code generated by embedgen. DO NOT EDIT.
package {{.Package}}

import "encoding/base64"

var assets = map[string]string{
{{- range $path, $content := .Assets}}
    "{{$path}}": "{{$content}}",
{{- end}}
}

func Asset(name string) ([]byte, error) {
    data, ok := assets[name]
    if !ok {
        return nil, fmt.Errorf("asset not found: %s", name)
    }
    return base64.StdEncoding.DecodeString(data)
}

func MustAsset(name string) []byte {
    data, err := Asset(name)
    if err != nil {
        panic(err)
    }
    return data
}

func AssetNames() []string {
    names := make([]string, 0, len(assets))
    for name := range assets {
        names = append(names, name)
    }
    return names
}
`

func main() {
    flag.Parse()

    assets := make(map[string]string)

    filepath.Walk(*dir, func(path string, info os.FileInfo, err error) error {
        if err != nil || info.IsDir() {
            return err
        }

        data, err := ioutil.ReadFile(path)
        if err != nil {
            return err
        }

        relPath, _ := filepath.Rel(*dir, path)
        assets[relPath] = base64.StdEncoding.EncodeToString(data)
        return nil
    })

    data := struct {
        Package string
        Assets  map[string]string
    }{
        Package: *pkgName,
        Assets:  assets,
    }

    t := template.Must(template.New("assets").Parse(assetTemplate))

    f, _ := os.Create(*outputFile)
    defer f.Close()

    t.Execute(f, data)
}
```

Note: For Go 1.16+, prefer using `//go:embed` directive instead.

## Best Practices

### 1. Include Generation Comments

```go
// Code generated by mygen. DO NOT EDIT.
package example

// This tells tools (and developers) this file is generated
// go fmt will recognize this pattern
```

### 2. Make Generation Reproducible

```go
// BAD: Non-deterministic output
//go:generate sh -c "date > version.go"

// GOOD: Deterministic based on inputs only
//go:generate stringer -type=Status
```

### 3. Version Your Tools

```go
// Makefile or script to ensure correct tool versions
//go:generate go install golang.org/x/tools/cmd/stringer@v0.1.12
//go:generate stringer -type=Status

// Or use go.mod tool dependencies (Go 1.17+)
```

### 4. Document Generation Requirements

```go
// file: doc.go
/*
Package models contains database models.

Code Generation:
This package uses go generate. Before committing, run:

    go generate ./...

Required tools:
    go install golang.org/x/tools/cmd/stringer@latest
    go install github.com/golang/mock/mockgen@latest

Generated files:
    - status_string.go (from stringer)
    - mocks/*.go (from mockgen)
*/
package models
```

### 5. CI/CD Verification

```yaml
# .github/workflows/ci.yml
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-go@v4
        with:
          go-version: '1.21'

      - name: Install generators
        run: |
          go install golang.org/x/tools/cmd/stringer@latest

      - name: Verify generated code
        run: |
          go generate ./...
          git diff --exit-code || (echo "Generated code out of date" && exit 1)
```

## Common Pitfalls

### 1. Forgetting to Run go generate

```bash
# Add pre-commit hook
# .git/hooks/pre-commit
#!/bin/sh
go generate ./...
git diff --exit-code
```

### 2. Generator Output Differs Across Environments

```go
// Use explicit versions and deterministic output
//go:generate stringer -type=Status -linecomment=false

// Avoid time-based or random content
// Sort maps before iteration
```

### 3. Circular Dependencies

```go
// BAD: Generator in same package needs generated code
//go:generate mygen -input=types.go  // mygen needs this package to compile!

// GOOD: Generator in separate module
//go:generate go run github.com/myorg/mygen@v1.0.0 -input=types.go
```

### 4. Missing Build Constraints

```go
// file: gen.go
//go:build ignore

// This file is only used for generation, not compilation
package main

//go:generate go run gen.go
```

## Performance Considerations

### Generation Time

```go
// Parallelize independent generators
//go:generate sh -c "stringer -type=A & stringer -type=B & wait"

// Or use make for dependency management
// Makefile
generate: status_string.go mock_repo.go

status_string.go: status.go
    stringer -type=Status

mock_repo.go: repository.go
    mockgen -source=repository.go -destination=mock_repo.go
```

### Incremental Generation

```go
// Only regenerate if source changed
// Most tools don't support this, use make/build system

// Makefile example
%.string.go: %.go
    stringer -type=$(basename $<) -output=$@
```

## Interview Key Points

1. **What is go generate**:
   - Scans for `//go:generate` comments
   - Runs specified commands
   - Generated code checked into VCS
   - Not run during go build

2. **Common tools**:
   - `stringer`: String methods for enums
   - `mockgen`: Mock generation for testing
   - `protoc`: Protocol buffer compilation
   - Custom generators

3. **Built-in variables**:
   - `$GOFILE`, `$GOPACKAGE`, `$GOLINE`
   - `$GOOS`, `$GOARCH`

4. **Best practices**:
   - "Code generated" comment
   - Reproducible output
   - Version control generated files
   - CI verification

5. **vs //go:embed**:
   - `go:embed` is for embedding files at compile time
   - `go:generate` is for running arbitrary commands
   - `go:embed` is built-in (Go 1.16+)
   - `go:generate` requires external tools
